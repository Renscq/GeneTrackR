GeneTrackR 0.7.7 remains a pure-R package.

Before running devtools::document(), devtools::test(), devtools::check(), or
installing the package, remove these legacy compiled-backend paths from the
GeneTrackR source tree if they are still present:

R/bw_cpp_backend.R
src/

IMPORTANT: extracting an incremental ZIP cannot delete files that already exist.
If test-pure-r-package.R reports compiled compatibility helpers in the namespace,
R/bw_cpp_backend.R is still present or an older GeneTrackR namespace is still
loaded. Delete the file/directory and restart the R session before retesting.

Under Git, the tracked-source cleanup is:

git rm R/bw_cpp_backend.R
git rm -r src

Also delete any untracked .o, .dll, .so, or other build artifacts left under src/.
