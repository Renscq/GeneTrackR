# Convert a GenePred object to GRanges

Convert a GenePred object to GRanges

## Usage

``` r
as_granges(object, level = c("gene", "transcript", "exon", "feature"))
```

## Arguments

- object:

  A GenePred object.

- level:

  Feature level. One of gene, transcript, or exon.

## Value

A GRanges object.
