# Summarize signal tracks within a region

Summarize signal tracks within a region

## Usage

``` r
summary_bwg(object, chrom = NULL, start = NULL, end = NULL, samples = NULL)
```

## Arguments

- object:

  A BwgTrack object.

- chrom:

  Optional chromosome name.

- start:

  Optional region start.

- end:

  Optional region end.

- samples:

  Optional sample IDs.

## Value

A data.table summary.
