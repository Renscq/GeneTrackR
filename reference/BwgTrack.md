# Create a BwgTrack object

Create a BwgTrack object

## Usage

``` r
BwgTrack(
  samples,
  data = NULL,
  meta = list(),
  validation = make_empty_validation()
)
```

## Arguments

- samples:

  Sample metadata table.

- data:

  Optional in-memory signal table.

- meta:

  Metadata list.

- validation:

  Validation result list.

## Value

A BwgTrack object.
