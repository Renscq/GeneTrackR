# Show the first rows of a BwgTrack object

Show the first rows of a BwgTrack object

## Usage

``` r
# S3 method for class 'BwgTrack'
head(x, n = 6L, ...)
```

## Arguments

- x:

  A BwgTrack object.

- n:

  Number of rows to show.

- ...:

  Additional arguments.

## Value

Invisibly returns the input object.
