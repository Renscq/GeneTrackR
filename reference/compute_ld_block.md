# Compute a linkage disequilibrium block from VCF genotypes

Calculates pairwise LD for variants in a genomic region. Genotypes are
parsed from the sample columns preserved by
`read_vcf(..., keep_genotype = TRUE)`. The current implementation uses
genotype dosage, where 0 is homozygous reference, 1 is
heterozygous/non-reference carrier, and 2 is homozygous alternate for
diploid biallelic records. Multi-allelic non-reference alleles are
collapsed into total non-reference dosage.

## Usage

``` r
compute_ld_block(
  vcf,
  chrom = NULL,
  start = NULL,
  end = NULL,
  variant_type = c("both", "snp", "ind"),
  method = c("r2", "Dprime"),
  samples = NULL,
  min_pair_samples = 3L,
  ploidy = 2L,
  keep_genotype_matrix = FALSE,
  verbose = TRUE
)
```

## Arguments

- vcf:

  A `VariantTrack` object returned by
  [`read_vcf()`](https://renscq.github.io/GeneTrackR/reference/read_vcf.md)
  or a VCF path.

- chrom:

  Chromosome. If NULL, a single-chromosome in-memory VCF uses its full
  chromosome range.

- start:

  Region start. If NULL, the minimum retained variant position is used.

- end:

  Region end. If NULL, the maximum retained variant position is used.

- variant_type:

  One of `both`, `snp`, or `ind`. `ind` keeps INS/DEL/MNV records.

- method:

  LD value used as the primary `ld` column. Currently `r2` and `Dprime`
  are supported. Dprime is a dosage-based approximation for unphased
  VCFs.

- samples:

  Optional sample names to keep.

- min_pair_samples:

  Minimum number of paired non-missing samples required for a pairwise
  estimate.

- ploidy:

  Ploidy used for dosage-based allele-frequency and Dprime
  approximation. Default is 2.

- keep_genotype_matrix:

  Logical. Whether to store the variant-by-sample dosage matrix in the
  returned object.

- verbose:

  Logical. Whether to print progress messages.

## Value

An `LDTrack` object.
