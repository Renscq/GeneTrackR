# GeneTrackR 0.99.11 real-data I/O assessment

The assessment compares GeneTrackR with VariantAnnotation for indexed VCF
and with rtracklayer for GFF3. It uses the source text as an independent
reference and stores file checksums, environment versions, unmatched rows,
field differences, and reader timings.

## Inputs and reproduction

The VCF is the 1000 Genomes chromosome 22 subset distributed with
VariantAnnotation and contains 10,376 variants and 5 samples on GRCh37.
The TBI comes from the same upstream revision.
[VariantAnnotation vignette](https://bioconductor.org/packages/release/bioc/vignettes/VariantAnnotation/inst/doc/VariantAnnotation.html)
and [pinned VCF and TBI](https://github.com/Bioconductor/VariantAnnotation/tree/dc8ecd11b893fdebfa561bca78205d909ce354a3/inst/extdata).

The annotation is the reference-chromosome comprehensive GFF3 on GRCh37.p13.
The script copies each chr22 record verbatim in source order, with a GFF3
version header and LF line endings. Each format is checked independently.
[GENCODE human release 19](https://www.gencodegenes.org/human/release_19.html).

Install GeneTrackR 0.99.11 from the checked source archive into a development
library with Rsamtools, VariantAnnotation, rtracklayer, and BiocManager.
From the repository root, download the data once and select a fresh report
directory for each machine. The following commands use a POSIX shell. On
Windows PowerShell, create the input folder with New-Item and use curl.exe
with the same source URLs and destination files.

```sh
input_dir=temp/real-io-inputs
mkdir -p "$input_dir"
vcf_base=https://raw.githubusercontent.com/Bioconductor/VariantAnnotation/dc8ecd11b893fdebfa561bca78205d909ce354a3/inst/extdata
gff_base=https://ftp.ebi.ac.uk/pub/databases/gencode/Gencode_human/release_19

curl --fail --location "$vcf_base/chr22.vcf.gz" \
  --output "$input_dir/chr22.vcf.gz"
curl --fail --location "$vcf_base/chr22.vcf.gz.tbi" \
  --output "$input_dir/chr22.vcf.gz.tbi"
curl --fail --location "$gff_base/gencode.v19.annotation.gff3.gz" \
  --output "$input_dir/gencode.v19.annotation.gff3.gz"

Rscript tools/assess_real_standard_io.R "$input_dir" temp/real-io-run
```

## Comparison criteria

- VCF uses the inclusive window 22:50443100-51000000. Source overlap is
  computed from start POS, REF width and INFO END. The script compares both
  the overlapping records and the records with POS inside the window.
  Keys contain CHROM, POS, REF, ALT and occurrence within that key. The
  audit counts generated display IDs and compares original IDs where present.
  It checks QUAL, FILTER, INFO AF and END, and FORMAT GT, DS and GL for all
  five samples in header order. Numeric fields use an absolute tolerance
  of 1e-7. The comparison records row-order differences.
- GFF3 rows are matched on sequence name, 1-based closed start and end,
  strand, feature type, original ID, original Parent and occurrence. The
  audit compares source, score and phase, and counts Parent tokens and
  repeated IDs. The chr22 data have one Parent token per child row.
- Each timed reader runs in a fresh R process. Namespace startup is measured
  separately and includes Rsamtools for both VCF readers. The script records
  three read times, returned object size, and process peak RSS in MiB.
  The read timer covers the reader call. Process peak RSS also includes
  namespace loading and result serialization. It comes from PeakWorkingSet64
  on Windows, VmHWM on Linux, and /usr/bin/time -l on macOS.

## Recorded results

Windows and Linux completed all comparisons with matching input checksums,
result counts and field-level results. Both used GeneTrackR 0.99.11,
R 4.6.1 and Rsamtools 2.28.0. Windows x86_64 used Bioconductor 3.24.
Linux x86_64 used Bioconductor 3.23 in the official Docker image on WSL2,
with the inputs copied to the container filesystem before measurement.
The image digest was
sha256:821dbf9ac119eac41f177531c7ca8fc7084c99c04eb218a1aa7f52cb63bad5d9.
macOS remains pending because no executor was available.

- VCF. All readers matched 8,771 overlapping records and 8,770 records with
  POS inside the interval. The extra record is a deletion that starts before
  the left endpoint and overlaps the interval. The POS slice contains
  829 missing IDs, six repeated positions and zero repeated allele keys.
  All five sample columns and 43,850 in-window site-sample combinations
  matched. The sample columns stayed in header order. Native and standard
  readers generated display IDs for the 829 missing source IDs. The native
  reader reordered some records with the same POS. The existing synthetic
  adapter tests cover repeated VCF IDs.
- GFF3. Both readers matched all 58,721 chr22 rows out of 2,615,566
  input rows, including 57,458 Parent links and 59 repeated ID occurrences.
  GeneTrackR returned rows in a different order. Their keys and compared
  fields matched.
